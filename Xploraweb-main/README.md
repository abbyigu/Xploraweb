
  # Xplora web

  ✅ **This is the production app root.** Vercel builds and deploys goxplora.ca
  from this directory. A separate, unused app tree also exists at the
  repository top level — it is legacy and does not affect production; do not
  make application changes there.

  This is a code bundle for Xplora web. The original project is available at https://www.figma.com/design/4I43kvPt98TlOvkt3E67y8/Xplora-web.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
